# Team Razor's Edge

**Live demo / pitch deck → https://yizyace.github.io/poc-hackathon-team-razors-edge/**

**VisionOps** is a three-agent pipeline that turns a photo of a damaged shipment into a
filed freight-claim dispute — or a flagged human escalation — in seconds: it reads the
damage from the photo, looks up the vendor and SLA, then either files the claim silently
or escalates it for review, leaving a full audit trail.

Orchestrated in [Phinite](https://phinite.ai) Graph Studio. Built at NY Tech Week's
"AI Agents: From Prototype to Production" hackathon (sponsored by Phinite × GMI Cloud).

**Docs:** [`/docs`](./docs) — start with the
[plain-language pitch](./docs/visionops-pitch-eli5.md) or the
[baseline spec](./docs/visionops-baseline-specification.md).
